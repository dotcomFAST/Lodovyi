# Тенісні корти на Льодовому — сайт

Статична сторінка + одна серверна функція для Vercel.

- `index.html` — сайт (десктоп, лаптоп, мобайл).
- `api/slots.js` — бере публічний розклад з `tennis-lodovyi.up.railway.app/book/schedule` і віддає вільні слоти як JSON. Кеш 30 с.
- Сітка на сайті оновлюється кожні 30 с і при поверненні на вкладку. Дні (14 вперед) береться з їхньої системи, тому новий день з'являється сам.
- Кнопка «Забронювати» веде на `/book/confirm?date=…&court=…&time=…` у їхній системі: там вхід через телефон/Telegram і запис у базу бота.

## Деплой

1. Створи репозиторій на GitHub і завантаж туди вміст цієї папки (Add file → Upload files, перетягни всі файли й папку `api`).
2. vercel.com → Add New → Project → Import цей репозиторій.
3. Framework Preset: **Other**. Build/Output налаштування не чіпати. Deploy.
4. Перевір: `https://<твій-домен>.vercel.app/api/slots` має повернути JSON з `days` і `free`.

Або з терміналу: `npm i -g vercel` → у цій папці `vercel` → `vercel --prod`.

## Якщо `free` порожній, а на їхньому сайті є вільні слоти

Значить, їхня сторінка змінила розмітку. Парсер шукає посилання виду `/book/confirm?date=YYYY-MM-DD&court=N&time=HH:MM` — перевір, чи вони ще є в HTML.

## Що налаштовується

- Корти й типи покриття: масив `COURTS` у `index.html`.
- Години: `HOURS` (зараз 08:00–22:00).
- Ціни: функція `price` у `index.html` (правила будні/вихідні, до/після 16:00).
